# TEP デジタルツイン構築における学術研究プロセス・フロー

このドキュメントは、テネシー・イーストマン・プロセス（TEP）データセットを用いた記号回帰・物理数式発見（LLM-GP）における、**学術的厳密性を担保するための検証プロトコルおよび研究フロー**を定義します。

---

## 1. 基本理念（学術的厳密性の厳守）

本プロジェクトは、単なる数値のフィッティングではなく、**「化学プラントの動的な物理・化学因果関係を解釈可能な数式として発見する」**学術研究です。そのため、データの取り扱いは極めて厳密かつ透明でなければなりません。

*   **事前合意プロトコル**:
    計算コストの削減や高速化のために、データセットの切り詰め（トランケーション）や代表サンプルの抽出（サブサンプリング）などの近似的処理を行う場合は、**必ず事前に研究責任者（人間）にその理由と影響範囲を報告し、合意・承認を得てから実行します。**
*   **絶対的な全域検証**:
    最適化の過程で部分データを使用したとしても、最終的な決定係数 $R^2$ および予測値の算出は、**必ず 5,000,000 行（500万行）のデータセット全域に対して検証（Validation）を行い**、その全域における真の精度をデジタルツインの性能として報告・ドキュメントに保存します。

---

## 2. 2フェーズ型・厳密検証プロトコル

500万行に及ぶ超巨大データセットに対して直接進化アルゴリズム（差分進化：DE）を何万回も反復評価すると、計算時間が膨大になる問題（フリーズや過度な遅延）が発生します。これを解決し、かつ厳密性を保つために以下の **「2フェーズ型ハイブリッド・フロー」** を採用します。

```
[500万行の TEP 訓練データ]
       │
       ├─► 統計的層化抽出 ──► [代表 50,000 サンプル] ──► 【フェーズ1: 係数最適化】
       │                                                         │
       │                                                    (最適なパラメータ)
       │                                                         │
       ▼                                                         ▼
【フェーズ2: 全域モデル検証】 ◄───────────────────────────────────┘
(500万行すべての行に対して数式を評価し、真の全域 R² を計算)
       │
       ├─► 合格（R² > 0.95） ──► デジタルツイン構成図（TEP_FLOW_DIAGRAM.md）への保存
       │                                 └─► ビジュアライザー（tep_visualizer.html）へ反映
       │
       └─► 不合格（R² <= 0.95） ──► 物理因果の再分析、数式の構造修正（LLMによる再探索）
```

### 【フェーズ 1】 代表サンプルによる係数最適化 (Optimization)
*   **プロセス**: 500万行のデータセットから、プロセスのすべての動的挙動（定常、過渡、故障遷移など）を統計的に網羅する **`50,000サンプル`** を抽出します。
*   **目的**: この 50,000 サンプルを評価関数に用い、差分進化法（DE）により数式モデル内の未定係数（$c[1], c[2]$ など）のフィッティングを高速かつ高精度に実行します。

### 【フェーズ 2】 500万行全域でのモデル検証 (Validation)
*   **プロセス**: フェーズ1で得られた最適パラメータ（係数）を固定した数式を用い、**5,000,000行すべてのデータに対して瞬時にベクトル演算による予測を行います。**
*   **目的**: 500万行全域に対する予測値と実際のTEPデータから、**「真の全域決定係数 $R^2$」** を厳密に計算します。
*   **合格基準**: この全域 $R^2$ が **`0.95`** を超えた場合のみ、「デジタルツイン構築完了」と判定し、次のステップへと移行します。

---

## 3. デジタルツインの統合と可視化

合格した（$R^2 > 0.95$ を達成した）物理モデルは、以下のステップでプラント管理システムに統合され、グラフ化されます。

1.  **プロット用データの保存 (`plot_data.json`)**:
    *   プラント稼働の先頭 2,000 ポイント（標準描画範囲）の「実際値」および「数式算出値」を取り出します。
    *   JSON ファイルの `r2` キーには、局所の値ではなく、**【フェーズ2】で検証された「500万行全件での真の決定係数 $R^2$」** を厳密に書き込みます。
2.  **適合比較プロットの生成 (`plot_graph.py`)**:
    *   `plot_data.json` を用いて、時系列波形の実際値と予測値の比較プロットグラフ（`.png`）を生成します。グラフのタイトルには、全域での真の $R^2$ と発見された数式が明記されます。
3.  **プラント構成図・ビジュアライザーへの保存**:
    *   数式と真の全域 $R^2$、および化学工学的な詳細解説（何故その数式が物理的に優れているか、時間遅れラグの妥当性など）を、`TEP_FLOW_DIAGRAM.md` および `tep_visualizer.html` に保存・統合します。
